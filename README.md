# 📱 Taskly

**Taskly** is a modern and polished Flutter task-management application designed to help users organize their daily tasks, prioritize what matters, and stay productive.

The app provides an intuitive interface for creating and managing tasks, setting priorities and due dates, tracking progress, and receiving reminders.

## ✨ Features

* 🔐 **User Authentication**

  * Secure sign up and login using Firebase Authentication
  * User-specific task management

* 📝 **Task Management**

  * Create, edit, and delete tasks
  * Set task priorities
  * Add due dates
  * Mark tasks as completed
  * Track task progress

* 🔎 **Search & Filtering**

  * Search through tasks quickly
  * Filter tasks based on their status and other criteria

* 📅 **Calendar**

  * View tasks based on their due dates
  * Easily keep track of upcoming tasks

* 🔔 **Local Reminders**

  * Receive reminders for important tasks
  * Stay notified about upcoming deadlines

* 👤 **Profile & Statistics**

  * User profile
  * Task completion statistics
  * Productivity progress

* ☁️ **Cloud Data**

  * Tasks are stored securely using Cloud Firestore
  * Data is synchronized with the user's account

## 🛠️ Technologies

* **Flutter**
* **Dart**
* **Firebase Authentication**
* **Cloud Firestore**
* **Provider** – State Management
* **GoRouter** – Navigation
* **Local Notifications** – Task reminders

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or Xcode
* Firebase project

### Installation

1. Clone the repository:

```bash
git clone https://github.com/MohamedAbdAlmawjoud/taslky.git
```

2. Navigate to the project:

```bash
cd taslky
```

3. Install dependencies:

```bash
flutter pub get
```

4. Configure Firebase for Android and iOS.

5. Run the application:

```bash
flutter run
```
